# go-kit

Forge's shared Go platform library: the transport, persistence, auth, JSON:API,
search and observability building blocks every forge service is built on.

```sh
go get github.com/fromforgesoftware/go-kit@latest
```

Requires Go 1.25+. Consumed by the forge services (aegis, talos, gjallarhorn,
gleipnir) and the forge console server. Game/simulation packages live in
`game-kit`, not here.

## Packages

### Service layers

| Package | What it is |
|---|---|
| `application` | Clean Architecture application layer: `repository` and `usecase` building blocks |
| `resource` | Base abstractions for domain entities |
| `errors` | Structured errors with rich context |
| `filter` | Generic specification pattern for filtering resources |
| `search` | Turns the `search/query` DSL (filter / sort / fieldsets / includes / pagination) into repository and list-endpoint options |

### Transport

| Package | What it is |
|---|---|
| `transport` | Cross-cutting `Endpoint` and transport error contracts |
| `transport/rest` | HTTP server, client and route registration |
| `transport/grpc` | gRPC server, client, interceptors and health checks |
| `transport/websocket` | WebSocket client and hub server |
| `transport/tcp` | TCP server and client framework |
| `transport/udp` | UDP transport with optional reliability |
| `transport/amqp` | RabbitMQ producer and consumer |
| `transport/nats` | NATS / JetStream consumer and publisher |
| `jsonapi` | JSON:API 1.1 server-side encoding and decoding |
| `openapi` | OpenAPI 3.1 documents generated by reflection |

### Persistence

| Package | What it is |
|---|---|
| `persistence` | Database-agnostic primitives (`Transactioner`, …) |
| `persistence/postgres` | Postgres error translation (SQLSTATE → kit errors) and advisory locks |
| `persistence/gormdb` | GORM client, transactions and locking (`gormpg` for Postgres) |
| `persistence/sqldb` | `database/sql` client |
| `persistence/redisdb` | Redis client and repository |
| `migrator` | Database migrations |

### Auth

| Package | What it is |
|---|---|
| `auth` | Authentication primitives and middleware |
| `auth/jwt`, `auth/password` | JWT signing/verification and password hashing |
| `auth/oidc` | OIDC client: discovery, PKCE redirect, ID-token verification |
| `auth/provider` | `IdentityProvider` port the HTTP and gRPC authenticators delegate to |
| `firebase` | Firebase Authentication client |

### Observability

| Package | What it is |
|---|---|
| `monitoring/logger` | Structured logging |
| `monitoring/tracer` | OpenTelemetry tracing |

### Utilities

| Package | What it is |
|---|---|
| `decimal` | Fixed-point decimal for money and crypto |
| `retry` | Retries with configurable backoff |
| `saga` | Saga pattern for distributed transactions |
| `instance` | Instantiating generic types |
| `ptr`, `slicesx` | Generic pointer and slice helpers |
| `proto` | Generated platform protobuf |
| `pb` | `Any` and `Timestamp` protobuf helpers |

### Testing

| Package | What it is |
|---|---|
| `golden` | Golden-file test helpers |
| `fixtures` | SQL fixtures from embedded filesystems |
| `sops` | Loading SOPS-encrypted config in tests |
| `*/…test` | Mocks and helpers next to each package (`resttest`, `gormdbtest`, `loggertest`, …) |

## Development

```sh
make test              # go test ./...
make test-race         # with the race detector
make test-integration  # integration-tagged tests
make lint              # golangci-lint
make mock              # regenerate mocks (mockery)
buf generate           # regenerate protobuf from proto/
```
